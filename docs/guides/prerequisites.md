# 接入准备

开始 SDK 集成前，请确认以下前置条件已就绪。任一项缺失，请先联系平台管理员。

## AccessKey ID / Secret

SDK 的身份凭证对，用于向 Edge 服务进行签名认证。在控制台创建 Deployment 时生成。

- **使用**：SDK 初始化时作为身份凭证传入，运行期不变。各平台具体字段名见各 Demo 仓库的「参数说明」（见 [平台与框架](platforms.md)）
- **注意事项**：建议应用开启混淆，避免 AccessKey 泄漏

## Edge 初始化节点地址列表（调度域名 + 预置 EIP）

SDK 寻址 Edge DoH 服务的入口——属于 [**调度域名**](../introduction/whitepaper.md#调度域名) 范畴（与业务域名严格区分）。

- **对应 SDK 参数**：`edgeNodes`（Android / iOS / Flutter 同名）
- **数量要求**：至少 1 个；推荐多个（域名 + IP 混用）——IP 作为**预置 EIP**（冷启动入口与最后兜底），域名经公共 DoH 解析作为中间回退；运行期 Edge DoH 还会再下发**策略分配 EIP** 作为最优入口
- **来源**：
    - **自部署边缘**：客户自行部署的 Private Edge 节点地址（EIP）
    - **订阅边缘**：订阅其他租户后获得的 CNAME 域名或 EIP 地址
- **注意事项**：
    - 初始化地址中的域名必须能通过外部公共 DNS 解析
    - 配置了域名时，SDK 启动后会优先通过 Edge DoH 解析域名获取 Edge 地址（即上述"策略分配 EIP"）

完整字段定义见 [参考 / 初始化参数 / Edge 节点地址列表](../reference/init-parameters.md#edge-节点地址列表必填)；3 层 EIP 兜底机制见 [白皮书 / AxisNow Edge DoH（AED）](../introduction/whitepaper.md#axisnow-edge-dohaed)。

## 控制台添加资源配置（可选）

每个需要由 SDK 接管的**业务域名**（业务流量的目标域名，如 `api.app.com`）都需要在控制台**定义为一个资源**，关联到对应的源站及基础属性。

- **为什么关键**：未包含在控制台资源中的域名，SDK 不会接管——按系统 DNS 直连源站
- **配置内容**：资源域名、源站地址、路由策略、安全策略
- **白皮书对应概念**："资源" 是 SDK 文档对白皮书中"域名 + 源站 + 路由策略 + 安全策略"组合的统称，详见 [术语表 / 资源](../introduction/glossary.md#5-凭证与配置)
- **详见**：**控制台配置指南**（请参考产品控制台文档）

## 控制台添加 Edge DoH 路由规则（可选）

为**业务域名**配置 **Edge DoH 路由规则**——决定 Edge DoH 基于客户端上下文（设备信息、网络环境、风险等级等）为每次请求返回哪个数据面节点（Private Edge 或 Public Edge）。

推荐为需要保护的资源域名，和初始化地址中的调度域名，配置 Edge DoH 路由规则。未添加则命中默认规则，走第三方公共 DNS 解析后响应。

- **启用步骤**：完整启用步骤（控制台 + SDK 两侧）见 [启用 EdgeDoH](enable-edgedoh.md)
- **详见**：**控制台配置指南**（请参考产品控制台文档）

## 获取 SDK 包

在控制台 **端点 → 设备** 界面，根据应用类型获取对应平台的 SDK 包。

- **来源**：SDK 官方发布渠道
- **版本选择**：使用当前稳定版本；各平台最低 SDK / 系统版本要求见 [平台与框架](platforms.md)
